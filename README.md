# virtualStyle Development Base

Central storage for miscellaneous files and utilities used by virtualStyle for various purposes (primarily prototyping).

## CDN Files

Top level css, js,and img directories are for providing files via Jsdelivr CDN links. This assists with rapid prototyping, enabling copy/paste of lines and single file templates that allow immediate experimentation with a standardized foumdation without having to shuffle a bunch of files and set up a bunch of directories.
